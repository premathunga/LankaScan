# LankaScan Pro - Complete Offline Scanner
Free, 100% Offline, No Ads, No Internet - Better than CamScanner & Claude's CamPDF

Features:
- CameraX + System Camera + Gallery import (3 ways to scan - always works)
- Auto Edge Detection (Blur + Sobel + Quad Scoring)
- Perspective Crop with draggable corners
- 5 Filters: Original, Lighten, Enhance, No Shadow, B&W (Morph Close + Blue Ink + Contrast LUT)
- Multi-page Review: Rotate, Reorder, Delete, Re-filter
- A4 Standardized PDF Export (High / Balanced / Compact)
- PDF Viewer, Search, Rename, Share, Delete
- Sinhala / English, Dark Theme
- No INTERNET permission, No Firebase, No Ads
